# Viagem Pela Terra Media
Implementação de diferentes tipos de buscas para encontrar o melhor caminho para navegar pela Terra-Média, ambientada no universo de Hobbit e Senhor dos Anéis. 

OBS: Para tentar fazer alguns contornos nos trajetos do mapa, adicionei alguns nós intermediários que não representam nenhuma localidade, eles não estão marcados na interface do mapa, mas participam da busca.

**Requisitos e execução da aplicação**

Para executar a aplicação, é necessário ter o **Python 3** instalado, com o **Tkinter**, utilizado na interface gráfica. Também é preciso instalar a biblioteca **Pillow**, responsável por carregar a imagem do mapa. Mantenha a estrutura dos arquivos e execute:

   ```bash
   python main.py
   ```

Após abrir escolha a origem, o destino e o algoritmo de busca. Caso deseje ver o funcionamento de cada algoritmo, aumente o intervalo da animação dos nós para ver a animação da busca.
